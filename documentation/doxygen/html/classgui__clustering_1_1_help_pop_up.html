Detailed Description

A popup window for displaying documentation pages.

The HelpPopUp class creates a wxPython-based window that embeds multiple documentation pages in a tabbed interface using wx.Notebook and wx.html2.WebView. It supports Markdown (.md) files by converting them to HTML before rendering.
